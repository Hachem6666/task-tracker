Mid-Course Reflection
Throughout this module, I used both the VS Code AI assistant (Copilot) and claude  to support my development work. I mainly used the VS Code AI assistant while writing and modifying code, asking it to explain existing code, suggest implementations, and help diagnose failing tests. I used claude to clarify requirements, understand debugging concepts, and review my progress when I wanted a second explanation or a simpler breakdown of a problem.
One example of AI helping me was during the implementation of the due dates and tags feature. The initial gap analysis and implementation plan accurately identified what needed to be added, which gave me a clear roadmap before I started coding. Later, the D1 behaviour contract and the E1 edge-case brainstorming also helped me think about expected behaviour before writing or changing code, making the development process more structured.
There were also situations where AI slowed me down because I still needed to verify its suggestions carefully. For example, I had to manually correct an indentation problem in models.py, and another suggestion resulted in a pasted test being nested inside another test in test_tasks.py. I also investigated what appeared to be a bug in the overdue and tag filters, but after checking further, I found it was caused by a stale save or cache issue rather than incorrect application logic. These experiences showed me that AI suggestions can be useful starting points, but they should never replace careful review.
Reviewing the code and test results changed the outcome of my work several times. Before implementing the overdue feature, I confirmed that completed tasks should never be treated as overdue, which prevented incorrect behaviour. I also caught indentation problems before they caused larger issues and used debug output to separate a real bug from a caching artefact. These checks gave me confidence that the final solution was correct instead of simply trusting the AI's recommendations.
This module reinforced that AI is a valuable development assistant, especially for planning, explaining code, and debugging, but the final responsibility for correctness remains with me. In future modules, I will continue making small, focused changes, reviewing diffs carefully, and verifying every AI-generated suggestion by running tests and checking the results myself.
