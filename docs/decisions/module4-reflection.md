# Module 4 Reflection

**Module:** 4 (CI + local Docker verification)

## Reflection Note

**GitHub Copilot:** From the earlier modules, I found GitHub Copilot most useful while writing code. It was good at suggesting small code changes, completing functions, and helping me move faster without leaving the editor. However, I still needed to review its suggestions because it only focused on the code I was working on, not the whole project.

**Claude Code:** During this module, Claude Code was the best tool for larger tasks involving the whole repository. It helped update documentation, fix conflicts in CLAUDE.md, identify why the CI workflow failed due to the missing pytest dependency, and debug the tags issue. It could work across multiple files and run commands, but I still had to review the results and make decisions instead of accepting every change automatically.

**Cursor/Codex:** I didn't use Cursor/Codex during this module, so I can't make a fair comparison based on my own experience. Rather than guessing, I would prefer to evaluate it after using it on a real project. From this module alone, I can only compare GitHub Copilot and Claude Code because those are the tools I actually worked with.
